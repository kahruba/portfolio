# My Portfolio Website

Welcome to my personal portfolio website! This project showcases my personal introduction, educational background, technical skills, interests, and future goals.

## About the Project

This is a personal portfolio website developed to present my profile and academic information in a simple, clean, and user-friendly design. It contains three main pages: Home, About Me, and Education.

## Features

- **Home Page:** Introduction, profile picture, education, skills, and contact information.
- **About Page:** Personal introduction, interests, strengths, and future goals.
- **Education Page:** Academic background, university information, and previous academic achievements.
- **Show More / Show Less:** Interactive button to display or hide additional academic details.
- **Responsive Design:** Adjusts the layout for different screen sizes.
- **Contact Section:** Includes email, phone number, and LinkedIn profile link.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Make sure all HTML, CSS, JavaScript, and image files are in their correct locations.
4. Open `index.html` in your web browser.
